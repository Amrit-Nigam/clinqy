This acceptance ledger records the measured scope from the [2026-11-03 validation pass](../../implementation-notes/validation.md): Apple Silicon (arm64), macOS 27.0, Google Chrome 156.0.8078.80 and installed Clinqy 0.3.1. Initial runs used compatible extension build `2026-11-browser-reliability-1`; the corrected signed app is installed and its connected Chrome handshake confirms `2026-11-browser-reliability-2` (shared extension version 1.9.16). Corrected live retests completed, and an explicit CLI reload proved stale helper 6 was replaced with byte-identical bundled helper 7. A fixture pass does not establish compatibility with every app, website, display or provider configuration. Initial failures and corrected runs are retained separately.
